测试鸭是由程序员鱼皮开源的免费交互式网络安全自学网站与游戏化 Web 安全靶场平台，将真实网站遭遇攻击的经验教训转化为 30 多个实战漏洞闯关关卡，涵盖逻辑漏洞、越权访问、XSS 跨站脚本、SQL 注入思维、接口绕过、前端校验缺陷与异常并发等常见安全问题。项目由面试刷题站点改造而来，基于 React、Umi、TypeScript、Ant Design Pro 与 Intro.js 纯前端架构实现，通过 Mock 数据静态化与埋点式游戏机制实现零后端依赖，支持本地一键启动与离线体验，配套请求调试工具箱、血鸭值积分面板、新手指引与知识点解析，非常适合网络安全初学者、前后端开发者与高校计算机学生实战学习 Web 安全防护并参考前端模块化与状态管理设计。
