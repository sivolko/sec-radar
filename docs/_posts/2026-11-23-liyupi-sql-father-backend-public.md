SQL Father（SQL 之父）模拟数据与建表 SQL 生成平台的开源 Java 后端服务，由程序员鱼皮打造，支持可视化建表、智能导入、SQL 语句解析与 Excel 导入等多种输入方式，一键生成建表 DDL、批量插入 SQL、随机与正则模拟数据、JSON 数据以及 Java 和前端代码，并提供词库、表结构与字段信息的社区共享与管理后台。后端基于 Spring Boot、MyBatis-Plus、MySQL 与 Spring AOP 构建，融合统一 Table Schema 抽象、Druid SQL 解析、FreeMarker 模板引擎、Datafaker、EasyExcel 及策略、工厂、建造者与门面等多种设计模式，支持 Docker 部署，适合开发测试提效与实战学习。
